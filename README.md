MineLand Center

Requisitos:
- Python 3.10 o superior
- Flask
- SQLite

Instalación:
1. Instalar dependencias:
   pip install flask

2. Ejecutar:
   python app.py

3. Abrir en navegador:
   http://127.0.0.1:5000

Funciones:
- Gestión de productos
- Gestión de ventas
- Control de inventario
- Dashboard administrativo
- Carrito de compras
